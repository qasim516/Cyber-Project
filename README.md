# Cyber-Project — Verstech Cybersecurity Internship

A 6-week defensive cybersecurity assessment project, following the process:
**Scope → Discover → Scan → Analyze → Rate risk → Report → Retest**

## About this project

This repo documents a hands-on cybersecurity internship project. Each week
focuses on a different stage of security assessment — from fundamentals and
lab setup, through vulnerability scanning, web application testing, network
traffic analysis, and incident response — ending in one consolidated final
report and presentation.

> **Lab note:** Due to hardware limitations, this project uses hosted,
> sandboxed lab environments instead of local virtual machines —
> mainly **PortSwigger Web Security Academy**, with **TryHackMe**
> planned for network and incident-response exercises. All targets
> tested are lab instances created specifically for practice. No
> real-world or third-party systems are tested.
